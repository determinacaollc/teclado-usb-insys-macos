# Instaladores

Esta pasta guarda a versão atual dos instaladores da app `Brilho Philips`.

Para versões futuras, o fluxo recomendado é:

1. Criar o `.pkg` e o `.dmg`.
2. Criar uma tag, por exemplo `v2.0`.
3. Publicar os instaladores em `GitHub Releases`.

Isto mantém o histórico mais limpo e evita que o repositório cresça com muitos binários antigos.
